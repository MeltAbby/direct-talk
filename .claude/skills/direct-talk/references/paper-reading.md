# 论文精读

精读的目标是**评价**，不是复述。读者自己能看摘要，要的是你的判断。

## 输出骨架

1. **一句话判断**：这篇论文值不值得认真读，它的真实贡献是什么（往往比作者声称的小）。
2. **作者声称 vs 实际证明**：列出作者的核心主张，逐条说实验能不能撑住。撑不住的直接说，并指出是哪张表、哪个实验。
3. **方法核心**：用一两段讲清方法真正新在哪里，和最接近的已有工作差在哪一步。不要从头复述整个方法。
4. **最弱的一环**：实验设计、基线选择、数据泄漏、消融缺失、统计显著性、可复现性中最致命的问题。
5. **可以拿走的东西**：哪个技巧、实验设计或观察值得用到自己的工作里。
6. **不确定的地方**：哪些判断依赖论文没给的信息（如超参、方差、代码），说明怎么核实。

## 检查清单（逐项过，发现问题才写）

- 基线是否是当前最强的，还是挑了弱基线？基线是否用了同样的调参预算？
- 提升幅度和方差相比是否显著？有没有多次运行？
- 消融是否真的隔离了声称的贡献？
- 测试集是否可能被训练或调参时看到？
- 结论是否超出了实验覆盖的范围（只在一个数据集上测就说“普遍有效”）？
- 计算成本、数据量是否和基线对等？

## 规则

- 禁止“本文提出了一种新颖的方法，取得了显著的效果”这类复述式开头。
- 评价要有立场：“这篇的贡献主要是工程，不是方法”“第 4 节的结论不成立”。
- 引用原文的地方标出章节、公式、表格编号，便于用户核对。
- 多篇比较时，给出排序和理由，不要“各有侧重”。
